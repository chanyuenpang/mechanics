# Game-Graph需求与范围

状态：2026-08-31 需求与设计，已按后续确认收敛概念表/机制图导航；实际验证范围以开发路线和架构设计为准。

## 产品目标

为游戏设计者提供浏览器中的因果规则图工作台。将规则抽象为概念和促进/抑制关系，在不同颗粒度以及基础规则、关卡、敌人、手牌等组合范围内分析作用路径和设计疑点。分析对象是抽象规则，不是实时战局；关卡和手牌图表示纳入分析的规则组合，不承载当局血量、体力、目标实例或行动进度。

工具面向多种游戏，不能依赖任何宿主的规则实现、资产格式、游戏引擎或编辑器。工具源码独立管理；设计者编辑的节点定义图和分析文件保留在所分析游戏的项目目录，由该项目版本管理。

## 已明确的方法论

1. 节点表达概念；输入侧和输出侧都允许零条、一条或多条关系。
2. 连线方向为影响方向。正向表示源概念增多、增强或更可能发生时，目标也沿定义的方向增加；负向则抑制目标。正负不等于玩家视角的好坏。
3. 节点需要说明自身含义和变化方向。例如“敌人伤害”应明确为敌人造成的伤害，而不是敌人受到的伤害。共享“近战”概念正是接合机制的方式：敌人产出近战，某规则抑制近战，就能建立抽象抑制关系，不必核对某一局行动是否可执行。
4. 在适用条件一致的单条路径上，符号相乘可以解释间接影响；不计算胜率、影响强度或多条路径的净效果。
5. 单入单出的中间节点允许折叠成一条关系；折叠只改变视图，不删除源节点、来源、条件和中间步骤。重新展开应可恢复。
6. 折叠资格按当前组合网络判断，不能先把源图破坏性简化再叠加；自环、循环、分支和并行关系必须保留。
7. 孤立、只有输入没有输出、连接结构相似是设计疑点，不是自动判坏、合并或删除的理由。终点、资源消耗出口和未纳入当前分析范围的作用均需设计者判断。
8. 相似性比较只在相同范围和颗粒度下成立。费用、数值、时机、获得频率、条件等差异不能因为拓扑相似而丢失。

## 核心产品能力

| 能力 | 用户行为与结果 |
| --- | --- |
| 工作区 | 打开某个游戏的分析目录，不需要启动游戏 |
| 统一节点定义 | 在全局概念表维护共享节点 ID、名称、定义与变化方向，查看被哪些机制图引用 |
| 机制图 | 新建、命名、编辑、保存独立文件；引用窗口内搜索或新建共享概念，可批量引用，再编辑关系 |
| 组合浏览 | 同时启用任意多张机制图，公共概念按 ID 接合，保留每条关系的来源 |
| 编辑归属 | 点击机制仅显示和编辑自身；视图里的源规则只读，通过「编辑源机制」进入单图并可返回原视图 |
| 视图文件 | view v2 注册有序子机制并为每项保存 Visible；注册、显隐、组合位置与折叠自动写回，重开读取最新源规则；视图不拥有机制布局和规则草稿 |
| 影响解释 | 查看从某节点到某结果的路径、逐段符号、累计符号和机制说明；共享概念可直接揭示抽象协同与反制 |
| 设计疑点 | 提示当前范围内的孤立、作用出口、结构相似、相反作用路径，并展示证据 |

“基础”“关卡”“手牌”是机制图的用途，不是不同的文件格式或强制继承层级。每个工作区有自己的统一定义图；不同游戏同名节点不会自动认定为同一概念。

## 页面与主要流程

- 顶部：全局「概念表｜机制图」，区分共享定义维护与关系编辑。
- 左侧：视图置顶，当前视图下只列已注册子机制及 Visible 按钮；视图行的添加按钮从可搜索候选注册机制。全局机制在下方按真实目录呈现，可折叠、按名称、ID 或路径筛选，并负责单图打开与新建。全局目录不再同时承担视图成员清单。不暴露配置、定义文件、空目录占位或旧组合分类。
- 剩余全屏区域：行内概念表或叠加分析画布，图中提供引用概念、连线、缩放、选择和折叠/展开。
- 选中时浮出属性：概念含义、变化方向、来源与路径解释；不占用固定右栏。

完整编辑流程：打开工作区 → 新建机制 → 在引用窗口复用或新建共享概念 → 连线并注明符号/条件 → 保存机制 → 新建视图并注册子机制 → 用 Visible 控制当前投影 → 解释作用链和设计疑点。概念表可提前维护或编辑已有定义；需要修改源规则时进入单机制，保存后返回视图。

窗口内新建保留名称、含义、增加方向三项必填，不改变定义语义。提交前取消零写入；提交先保存共享定义，再加入原机制草稿，机制仍手动保存。失败不能假称没有写入，也不能盲目重建。ID 区分概念身份，同名提示复用但允许明确新建。

节点定义变更与图编辑分离。重命名不改变 ID；删除被引用的节点必须阻止并列出引用者。组合浏览不能偷偷覆盖来源图的定义或关系。

## 本轮交付边界

已交付独立仓库、源码分层、JSON Schema、跨文件校验、图算法、文件读写、极简网页编辑器、Layer 管理、视图自动记忆、示例工作区与项目接入。以领域/HTTP/文件测试和隔离工作区的浏览器编辑回读验证。
