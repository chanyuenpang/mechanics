# 网页节点编辑器

本地服务从启动时固定的工作区根读写 JSON，显式参数优先，否则向上定位。悬停侧栏工作区名称可查看完整根路径；不连接游戏运行时，不使用浏览器缓存代替保存。界面为浅色极简样式：左侧文件目录，其余区域为画布或节点名词表；属性在需要时浮出，侧栏可以收起。

## 文件与图层

- 顶部「概念表｜机制图」切换全局工作视图；侧栏固定上方视图、下方机制。两区右侧「＋」分别新建空白视图和独立机制，不显示 workspace.json、统一定义文件或旧叠加组合分类。
- 根内任意普通目录的 `*.mechanic.json` 在界面称为「机制」，`mechanics/` 是默认落点。点击机制名称退出视图，只显示该文件自身的节点和关系；机制模式不显示勾选框。
- 打开 `.view.json` 后，视图条目下只展示已注册子机制。Visible 按钮只切换显示；视图旁的「＋」打开搜索候选并注册新子机制。点击子机制名称仍然打开单图，不改变原视图的注册或显隐。共享节点按 ID 接合，关系详情保留源机制。
- 机制模式可修改关系，手动保存到当前机制。视图中的源规则只读，详情提供「编辑源机制」；编辑完成点击「返回视图」，读取最新规则并恢复组合位置和本页相机。
- 机制中拖节点修改该机制的局部位置；视图中拖任何节点只修改视图位置并自动保存。视图位置不被源机制的布局抢占；新出现节点使用确定初始位置，不重新排布已有节点。
- 机制区及各级真实目录均可折叠，支持鼠标、Enter 或空格操作；按名称、ID、相对路径筛选。搜索时临时展开命中的目录，清除后恢复原折叠。筛选和目录折叠仅保留在当前页面，不改画布、勾选、文件或撤销记录。
- 当前视图显示「可见数 / 注册数」。全局机制筛选不改变这两个数量；新机制成功打开后会清除筛选并展开所在目录，但不自动注册到原视图。
- 文件来自磁盘发现；视图按路径排序置顶，机制按真实目录组织，不显示空目录占位。悬停文件名可查看完整相对路径。外部新增/移动后点侧栏右上角重新读取，无需手工登记。

## 节点名词表

点击顶部「概念表」维护所有机制图共享的定义。表格参考 SJE Array 的紧凑表头、弱分隔线、行内输入和内部滚动样式，但工具不依赖 SJE 或宿主代码。

直接点击名称、概念定义、别名和标签编辑；每行的 Agent 锁由用户显式切换，锁定后 Agent mutation 不得修改或删除该概念。点击「新增概念」或表尾「新增一行」创建草稿行并聚焦名称。稳定 ID 自动生成且只读，改名不改引用；名称与定义必填，未完整填写无法保存，草稿会保留。顶部搜索按名称、ID、定义、别名或标签筛选，不修改文件。行内箭头进入引用此概念的机制图并定位节点，未引用的概念没有跳转目标；删除仍检查所有图层引用，已引用概念不可直接删除。

概念表草稿归共享定义文件，机制图草稿归当前分析文件。切换前有未保存修改时，可保存、放弃或取消；页面只保留一份当前文件草稿。进入概念表不改变记住的分析文件、可见层和折叠状态，返回机制图继续原来的范围。保存定义后，所有引用图层显示新名称；修改概念文案不会清空图层折叠。按 Ctrl+S 或顶部保存按钮落盘。

## 建图

1. 点击侧栏机制区右侧「＋」，填写名称、文件 ID、分析范围和相对目录。支持中文嵌套目录；填 `.` 表示根目录。此操作创建实际 JSON 文件，不写额外登记清单。空工作区也可以直接创建首张图。
2. 在机制图点击「引用概念」，搜索并勾选需要引用的共享概念；名称、ID、定义、别名和标签均可检索，已引用项显示「已在当前图中」。搜索框 Enter 勾选首个可选结果，不自动新建。
3. 需要新概念时点击「＋ 新建」，名称从搜索词带入，填写概念定义，然后「创建并引用」。同名先列出可复用概念，只有明确勾选同名新建才允许另建；不按名称合并。
4. 点击「＋→」「−→」「？→」，依次点击源概念和目标概念，建立影响关系。两端必须已被当前机制引用。正向影响使目标沿增加方向变化；负向影响使目标沿减少方向变化；随机影响表示目标可能增加或减少，不表示概率。相反方向的关系独立。
5. **is-a（特化 / 是某种）不通过连线创建**：在节点属性面板的「is-a 父概念」里输入名称、稳定 ID、别名或含义检索父概念，或在「新建概念 / 修改概念」对话框的「is-a 父概念」里同样检索指定；「清除」即移除。每个概念至多一个 is-a 父概念，候选不会列出自身与更具体的后代，禁止自连接与闭环，违反会被明确拒绝。
5. 选中节点或边，在浮动属性面板直接修改规则文字、关系或符号；条件约束直接写入规则文字，未填写规则的连线显示为灰色，或移除引用。再次点击当前图层名称可编辑名称与范围。
6. 悬停连线显示该连线的规则文字，保留换行；未填写时仅以灰色表示，不显示悬停提示。修改规则后悬停提示随草稿更新。
7. 点击「保存」或按 Ctrl+S。画布上的修改立即成为草稿，只有保存成功才显示「规则已保存」。

引用窗口提交前，搜索、填写和批量候选仅保存在窗口内；取消不写定义，也不改机制草稿。最终提交先保存共享定义，再把所有引用和新位置作为一次操作加入原机制草稿；不会顺便保存原机制的修改。新节点在当前视野附近寻找空位，不强制适应画布或移动已有节点。仅引用已有概念不保存定义；撤销本次引用不删除已落盘的共享概念。大批量节点可能延伸到当前画面之外，可主动适应画布查看。

创建失败或结果待确认时，输入保留并暂停重复提交。「重新读取并核实」只核实，不自动重试：若本次稳定 ID 与内容已经完整落盘，继续引用而不重复创建；若尚未落盘，用户可再次明确提交。源机制改变或 ID 内容不一致时拒绝继续，可导出本次输入和机制草稿后人工合并。已保存但未能加入机制时提供「继续引用」。关闭失败窗口不会丢弃本次会话，再次点「引用概念」继续处理；切换文件前须完成，或明确「结束本次引用」，已经写入的定义不会删除。

这不是跨文件原子事务。被任一图层引用的共享定义禁止删除。移出当前层会同时移除该层连接此节点的边，不修改其他层或全局定义。视图模式不提供创建或引用概念入口，需要先进入源机制。

## 独立视图文件与自动写回

1. 点击侧栏视图区右侧「＋」，填写名称、文件 ID 和相对目录，创建空的 `<ID>.view.json`；也可以在机制中使用画布上方的「存为视图…」。
2. 打开视图后，点击视图行旁的「＋」，搜索并注册子机制；新注册项默认 Visible。点击子机制右侧 Visible 按钮可以隐藏或再次显示，全部隐藏得到空画布，注册关系仍保留。
3. 当前视图名称显示在顶部，注册、Visible、节点拖动和折叠/展开自动保存。视图不提供规则连线或删除操作，源机制只读。
4. 点击文件树中的视图行，自动读取该视图注册的最新机制图；重复点击当前视图也会重新读取。不支持视图注册或叠加另一个视图。
5. 画布上方的「另存为…」创建新 ID 的独立视图文件，不改原视图。点击目录机制或「编辑源机制」进入单图，可用「返回视图」回到原组合。规则草稿须先保存、放弃或取消，再切换。

单机制最近打开仍使用协议既有的单成员内联 lastView，但不存单图临时折叠和相机；命名视图只记录 `{viewId}`，重启网页恢复该文件最新内容。没有 lastView 时只打开第一张机制，不自动叠加。旧内联多图或带展示状态的记录会显示只读预览，必须明确「保存旧叠加为视图」或「放弃旧叠加」后继续；启动不自动覆盖。当前工作区协议为 v8、definitions/mechanic v4、view v3；旧版本严格失败，只能显式迁移；历史 compositions 保留原文和校验。

折叠只在规则已保存、节点单入单出且不在有向环中时开放。摘要保留原始关系与来源，不能直接编辑。机制折叠仅为临时浏览，视图折叠自动保存。改变视图成员时保留仍存在节点的位置，仅清理失去引用的位置并展开失效折叠；整个动作可一次撤销。外部规则变化使保存的折叠失效时，提示明确「展开并打开视图」；取消保留当前文件，确认才修复视图。断引用或坏文件仍严格拒绝，不能部分加载。

规则文件不会自动保存。切换编辑文件或打开视图时，如有草稿，会询问保存、放弃或取消；选择放弃后，只有目标完整打开成功才替换草稿，打开失败仍保留原内容。关闭或刷新有草稿、未完成写入或写入失败/结果待确认的页面时，浏览器会提示。

自动保存失败后，状态显示「视图保存失败」或「视图写入待确认」，后续自动写入暂停。使用「导出视图草稿」保留当前选择；规则草稿另用「导出 JSON」。显式重新读取并处理草稿后才继续。队列中的快照绑定原目标，不会因快速切换而写入别的视图。

新视图创建与最近打开记录是两次提交。若前者成功、后者失败，会报告文件已创建及路径，当前画面保留。不要重复创建，先重新读取确认该文件；不会自动删除已创建文件。

## 画布操作

拖动结束时按节点左上角的画布坐标吸附到最近 20 的倍数，与缩放无关；多选节点分别对齐，原间距可能轻微变化。只吸附本次移动的节点，不重排已有布局；取消不写入，撤销恢复拖动前位置。机制仍手动保存，视图仍自动保存。

机制选择模式中，双击空白画布打开「概念节点」面板，与工具栏同名入口一致。单击、框选、平移及带修饰键的操作不会触发；视图只读规则、概念表及无机制时不打开。节点双击仍用于连线。新增位置继续使用相机中心的既有排布策略。

节点属性中的「修改概念」弹窗直接编辑共享名称、概念定义、别名和标签；Agent 锁只在概念表中由用户单独控制，不在普通文本编辑弹窗中隐式改变。保存仅写概念表，所有引用同步生效；保留当前机制草稿、选择和画布位置。取消不写文件。遇到冲突或写入结果待确认时保留输入，可导出修改后关闭弹窗并重新读取核实。

「追踪影响至」只列出当前机制或视图范围中可达的直接、间接节点：正向、负向与随机影响均顺箭头；特化不属于影响追踪路径；排除自身和无关节点，循环不会重复列出。没有下游时显示提示。折叠不会改变原始关系的可追踪范围。

机制选择模式下双击节点，以该节点开始连接，再点击另一节点创建一条边并退出连接状态。使用本页最后成功创建或修改的关系类型，初始为正向影响；只选中、切换工具、失败及撤销不改变记忆，刷新重置。Esc 取消，拖拽或 Shift 多选不会触发快捷连接，视图不允许建线。节点端点位于四边中点，根据位置自动选择；正反向及并行边错开，不保存手选端点。

| 操作 | 效果 |
| --- | --- |
| 空白处左键拖拽 | 框选与矩形相交的可见节点；反向拖框等价；轻点清除选择，Shift 轻点保留选择 |
| Shift 框选 / Shift 单击节点 | 追加选择 / 增减选中成员 |
| 拖拽选中节点 | 整组移动，一次撤销；机制手动保存，视图自动保存 |
| 自动排版 | 没有选中节点时重排当前可见的全部节点；选中节点后按钮显示“重排选中（N）”，只移动选中节点，未选节点位置严格不变 |
| 右键拖拽、空格＋左键拖拽或中键拖拽 | 平移画布；可从节点上开始，不改变选中集合或节点位置 |
| 鼠标滚轮、右下角加减 | 缩放 |
| F 或右下角适应按钮 | 将节点适应当前画布 |
| V / Esc | 返回选择工具 / 取消选择 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做当前文件操作，最多 80 步 |
| Delete | 删除当前层的关系或请求移除节点 |
| 结构提示 | 查看当前可见图层中的设计疑点 |
| 节点属性中的路径解释 | 追踪有限简单路径与来源，不推断胜率或净收益 |

撤销记录只属于当前文件，不跨文件或刷新恢复；视图与机制不互相撤销。机制保存后撤销会形成手动草稿，视图撤销会自动写回视图。画布相机不持久化；在同一页面返回已打开文件时恢复相机，普通文件点击或 Visible 切换不强制适应画布，需主动按 F。概念表往返保留原机制或视图上下文。

自动排版只由工具栏按钮显式触发，切换或勾选机制不会自动重排。没有选择和选中全部可见节点使用完全相同的完整排版；全选时按钮显示「自动排版（全部）」。完整排版先递归分组并联合安排节点与路线，随后检查每个独立区域的整体朝向：如果水平镜像能减少回流且不增加交叉与线长，就同步翻转该区域的节点与路线，再尝试调整回流子树，按关系符号改善水平阅读顺序。整体朝向检查不限制区域节点数量，不改变关系的真实起点和终点。选中子图使用相同算法重排内部，未选节点位置严格不变。两种操作均保留当前相机，节点与路径作为一次撤销记录提交；机制形成手动草稿，视图自动写回。

负面影响仅在后续水平调整中按反向评价：例如 X 对 Y 有负面影响，就按 Y → X 判断左右顺序，倾向于把 Y 放左边、X 放右边。图上仍显示真实的 X → Y 红色箭头；初始 ELK 排版、规则数据和上下方向的处理不变。水平调整保留节点纵坐标，竖直线段不产生方向惩罚；正面、随机和无符号关系沿用原方向判断。

完整排版最后会逐个收紧互不相连的区域。所有类型节点采用同一水平平移规则，不要求连线从左右端口出入；按 x 坐标从左到右迭代，保持区域内部节点的横向顺序、纵向位置、节点宽度与端口偏移，连线折点同步移动。仅接受线长缩短或横向占用减少且交叉等指标不变差的结果。独立区域最后整体摆放，区域之间无需保持全局 x 顺序；拖动时不会触发这轮全图紧缩。

自动排版的最终节点坐标也遵循 20px 网格。紧缩后逐个独立区域就近吸附；空间不足时以 5% 为步长等比放大节点间距和路线，再吸附，卡片尺寸保持不变。端口沿原侧面接回，保留原折线各段方向和至少 30px 的首尾接入段；每次候选都检查节点碰撞、穿节点、交叉、接触和重合。选取首个通过检查的比例，最多放大 50%，仍无可行结果时明确报错，不提交失败几何。放大会同时改变横纵坐标并增加线长；只整理选中子图时，外围节点和独立路线保持原样。旧文件不会在打开时自动吸附，点击自动排版才应用新规则。

正式连线重绘和自动排版在后台 Worker 中执行，新几何或新任务会取消旧计算。拖动后保留落点，只允许直接碰撞的近邻挪位；关联或被挡的路线局部更新，其余节点和路线原样保留。局部计算会尝试换端口、接回原通道及直接拉直，不会因计算困难转成全图整理。没有可行结果时显示错误。近邻微调与路线合并到同一次拖动编辑，撤销恢复拖动前的完整几何。重新打开优先恢复保存的路线，缺失时后台补算并固定全部节点；不承诺任意图都能消除全部交叉。

局部避障按当前全部节点核对缓存，不依赖拖动标记是否完整；显式选择的连线之外，被新位置挡住的旧线也会加入影响范围。外围固定路线参与通道评价，发现共线重叠时逐段平移局部路线，端口可沿原侧面滑动。提交前审计完整几何，拒绝穿节点、自交及任何涉及局部路线的共线重叠；外围既有问题保持隔离。松手后暂时隐藏等待计算的旧线，成功后显示新路线；失败显示错误，不用穿过新落点的旧线冒充计算结果。

局部避障完成后还会逐边消除多余折返：允许当前边独立换到相邻侧端口，也会用直线或一次转弯替换原路线的连续子路径。剪枝保持端口朝节点外侧出入、首尾至少 30px，不增加交叉与接触总数或共线重叠；每次减少折点，迭代到无法继续剪枝为止。路线评价在几何可行后优先减少交叉与折返，不会仅为改善平行线间距而保留回字形。必要的绕障和外围路线保留。

新计算的连线至少为 30px，折线靠近节点的首尾接入段也至少为 30px，按画布坐标计算。自动排版为每层子组保留这个间距；拖动后空间不足时，只调整直接近邻，或把拥挤的折线改为相邻侧端口的一次转弯。旧文件仍精确恢复已保存的布局，需要点击「自动排版」应用新间距。

同一对节点之间的关系统一规划为一条通道，再展开为间隔 12px 的平行线；正反方向、正负影响共用通道，各自箭头保持真实指向。绕障、转弯和简化以整组为单位，按展开后的实际宽度检查节点、其它线段与最短接入段。自动整理和局部刷新均使用此规则；新增或改动组内任意一条关系会更新整组，外围节点与通道保持隔离。算法版本更新会使旧路线缓存失效，重新打开时保留节点位置并重算路线。

多选状态不保存，不提供批量删除；左键框选仅在选择工具和画布空白处开始。右键平移在连线工具下也可使用，不产生连线。Esc、取消指针、失去捕获或窗口失焦会取消预览，不产生位置保存；手势期间不缩放。特化端点不能折叠；特化自连接和闭环明确拒绝。

## 文件安全与失败

同一工作区只允许一个服务持有 `.mechanics.lock`，浏览器多标签可连接同一服务。正常 Ctrl+C 关闭会释放锁。异常退出留下锁时，应确认无服务仍在使用该目录后手动清理；服务不凭 PID 自动抢锁。

每次保存按**本次写入涉及的资源**校验语义版本，并整体校验全工作区引用，然后使用同目录临时文件、flush、close、rename、回读确认。坐标、配色与连线路径属于展示数据，不参与版本比较。同一文件被其他写入者语义修改时返回冲突并点名文件，保留草稿；可先「导出 JSON」，再重新读取磁盘并手动合并。不提供强制覆盖按钮。

其他标签页保存别的文件、或打开图时补算坐标与连线路径，都不再改变本次保存所依据的资源版本；只有本次写入真正涉及的文件被语义修改时才会冲突。冲突提示中的「重新读取」与侧栏右上角刷新使用同一草稿保护；没有草稿可直接同步，有草稿会先提示处理。不会自动采用旧 revision 或悄悄重试。

新建机制图通过完整文件发布直接进入发现集合，不再另写清单。已有同名文件绝不覆盖；请求结果不明时应重新读取，不能自动重试。创建失败可能留下已经创建的空父目录；替换提交后确认失败或连接中断提示结果待确认。

只支持本地磁盘的单服务工作方式，不承诺外部编辑器并发写入的原子 CAS、掉电恢复、多文件事务、网络共享盘或多人协作。页面打开期间没有文件监听；需要读取外部最新修改时点击重新读取或刷新。保存期间不要让其他程序改写同一工作区。
