# 网页节点编辑器

本地服务从启动时固定的工作区根读写 JSON，显式参数优先，否则向上定位。根路径显示在侧栏；不连接游戏运行时，不使用浏览器缓存代替保存。界面为浅色极简样式：左侧文件目录，其余区域为画布或节点名词表；属性在需要时浮出，侧栏可以收起。

## 文件与图层

- 顶部「概念表｜分析图」切换全局工作视图；侧栏按真实目录混排分析图和视图文件，不显示 workspace.json、统一定义文件或虚拟叠加组合分类。
- 根内任意普通目录的 `*.analysis.json` 在界面称为「研究」，`analyses/` 是默认落点。点击研究名称退出视图，只显示该文件自身的节点和关系；研究模式不显示勾选框。
- 只有打开 `.view.json` 才能勾选研究，勾选只改变组合，不打开研究。点击研究名称仍然打开单图，不改变原视图的成员。共享节点按 ID 接合，关系详情保留源研究。
- 研究模式可修改关系，手动保存到当前研究。视图中的源规则只读，详情提供「编辑源研究」；编辑完成点击「返回视图」，读取最新规则并恢复组合位置和本页相机。
- 研究中拖节点修改该研究的局部位置；视图中拖任何节点只修改视图位置并自动保存。视图位置不被源研究的布局抢占；新出现节点使用确定初始位置，不重新排布已有节点。
- 文件树按服务从磁盘发现的真实路径生成，包括空目录；显示名用于辨识，悬停可查看完整相对路径。外部新增/移动后重新读取，无需手工登记。

## 节点名词表

点击顶部「概念表」维护所有分析图共享的定义。表格参考 SJE Array 的紧凑表头、弱分隔线、行内输入和内部滚动样式，但工具不依赖 SJE 或宿主代码。

直接点击名称、概念含义、增加方向编辑；点击「新增概念」或表尾「新增一行」创建草稿行并聚焦名称。稳定 ID 自动生成且只读，改名不改引用。三项定义必填，未完整填写无法保存，草稿会保留。顶部搜索按名称、ID、定义或方向筛选，不修改文件。行内箭头进入引用此概念的分析图并定位节点，未引用的概念没有跳转目标；删除仍检查所有图层引用，已引用概念不可直接删除。

概念表草稿归共享定义文件，分析图草稿归当前分析文件。切换前有未保存修改时，可保存、放弃或取消；页面只保留一份当前文件草稿。进入概念表不改变记住的分析文件、可见层和折叠状态，返回分析图继续原来的范围。保存定义后，所有引用图层显示新名称；修改概念文案不会清空图层折叠。按 Ctrl+S 或顶部保存按钮落盘。

## 建图

1. 点击顶部「概念表」，用「新增概念」填写名称、含义与增加方向，然后保存。
2. 点击侧栏「新建研究」，填写名称、文件 ID、分析范围和相对目录。支持中文嵌套目录；填 `.` 表示根目录。此操作创建实际 JSON 文件，不写额外登记清单。空工作区也可以直接创建首张图。
3. 在分析图点击「引用概念」，搜索并勾选需要引用的共享概念。
4. 点击「＋→」或「−→」，依次点击源节点和目标节点。两端必须已被当前层引用。符号表示促进或抑制，不是对玩家的好坏。黄色「＝→」则先点父类，再点其中一种，例如手牌释放包含后撤步。正负作用沿目标端包含关系传递，计算跳过等号，但方向、条件和来源仍保留；不反向扩散。首次添加包含只升级当前研究草稿为 v2，保存前可撤销或放弃，旧版工具无法读取保存后的 v2。
5. 选中节点或边，在浮动属性面板修改说明、符号或移除引用。再次点击当前图层名称可编辑名称与范围。
6. 点击「保存」或按 Ctrl+S。画布上的修改立即成为草稿，只有保存成功才显示「规则已保存」。

新概念必须先在统一定义中保存，再到分析层引用；不把两份文件的修改假称为一次原子事务。被任一图层引用的共享定义禁止删除。移出当前层会同时移除该层连接此节点的边，不修改其他层或全局定义。

## 独立视图文件与自动写回

1. 点击「新建视图」，填写名称、文件 ID 和相对目录，创建空的 `<ID>.view.json`；也可以在研究中使用「以此研究新建视图」。
2. 打开视图后，在研究旁勾选要叠加的文件。可全部取消得到空视图，取消勾选不删除源文件。
3. 当前视图名称显示在顶部，勾选、节点拖动和折叠/展开自动保存。视图不提供规则连线或删除操作，源研究只读。
4. 点击文件树中的视图行，自动读取该视图引用的最新分析图；重复点击当前视图也会重新读取。没有视图勾选框，不支持视图叠加视图。
5. 「视图另存为」创建新 ID 的独立文件，不改原视图。点击目录研究或「编辑源研究」进入单图，可用「返回视图」回到原组合。规则草稿须先保存、放弃或取消，再切换。

单研究最近打开仍使用协议既有的单成员内联 lastView，但不存单图临时折叠和相机；命名视图只记录 `{viewId}`，重启网页恢复该文件最新内容。没有 lastView 时只打开第一张研究，不自动叠加。旧内联多图或带展示状态的记录会显示只读预览，必须明确「保存旧叠加为视图」或「放弃旧叠加」后继续；启动不自动覆盖。旧命名视图按原编辑层计算位置，打开时不改文件，首次展示编辑才将位置写入视图并将历史 activeLayerId 置空。工作区协议仍为 v3，无新迁移步骤；历史 compositions 保留原文和校验。

折叠只在规则已保存、节点单入单出且不在有向环中时开放。摘要保留原始关系与来源，不能直接编辑。研究折叠仅为临时浏览，视图折叠自动保存。改变视图成员时保留仍存在节点的位置，仅清理失去引用的位置并展开失效折叠；整个动作可一次撤销。外部规则变化使保存的折叠失效时，提示明确「展开并打开视图」；取消保留当前文件，确认才修复视图。断引用或坏文件仍严格拒绝，不能部分加载。

规则文件不会自动保存。切换编辑文件或打开视图时，如有草稿，会询问保存、放弃或取消；选择放弃后，只有目标完整打开成功才替换草稿，打开失败仍保留原内容。关闭或刷新有草稿、未完成写入或写入失败/结果待确认的页面时，浏览器会提示。

自动保存失败后，状态显示「视图保存失败」或「视图写入待确认」，后续自动写入暂停。使用「导出视图草稿」保留当前选择；规则草稿另用「导出 JSON」。显式重新读取并处理草稿后才继续。队列中的快照绑定原目标，不会因快速切换而写入别的视图。

新视图创建与最近打开记录是两次提交。若前者成功、后者失败，会报告文件已创建及路径，当前画面保留。不要重复创建，先重新读取确认该文件；不会自动删除已创建文件。

## 画布操作

| 操作 | 效果 |
| --- | --- |
| 空白处右键拖拽 | 框选与矩形相交的可见节点；反向拖框等价，轻点不改变选择 |
| Shift 框选 / Shift 单击节点 | 追加选择 / 增减选中成员 |
| 拖拽选中节点 | 整组移动，一次撤销；研究手动保存，视图自动保存 |
| 空白处左键拖拽、空格拖拽或中键拖拽 | 平移画布 |
| 鼠标滚轮、右下角加减 | 缩放 |
| F 或右下角适应按钮 | 将节点适应当前画布 |
| V / Esc | 返回选择工具 / 取消选择 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做当前文件操作，最多 80 步 |
| Delete | 删除当前层的关系或请求移除节点 |
| 结构提示 | 查看当前可见图层中的设计疑点 |
| 节点属性中的路径解释 | 追踪有限简单路径与来源，不推断胜率或净收益 |

撤销记录只属于当前文件，不跨文件或刷新恢复；视图与研究不互相撤销。研究保存后撤销会形成手动草稿，视图撤销会自动写回视图。画布相机不持久化；在同一页面返回已打开文件时恢复相机，普通文件点击或勾选不强制适应画布，需主动按 F。概念表往返保留原研究或视图上下文。

多选状态不保存，不提供批量删除；右键框选仅在选择工具和画布空白处开始。Esc、取消指针、失去捕获或窗口失焦会取消预览，不产生位置保存；手势期间不缩放。包含端点不能折叠，纯包含路径只显示包含，不显示促进或抑制。包含成环会明确拒绝，保持原图；无效叠加可以返回源研究修正。

## 文件安全与失败

同一工作区只允许一个服务持有 `.rule-analyzer.lock`，浏览器多标签可连接同一服务。正常 Ctrl+C 关闭会释放锁。异常退出留下锁时，应确认无服务仍在使用该目录后手动清理；服务不凭 PID 自动抢锁。

每次保存校验整体 revision 和全工作区引用，然后使用同目录临时文件、flush、close、rename、回读确认。过期版本返回冲突，保留草稿；可先「导出 JSON」，再重新读取磁盘并手动合并。不提供强制覆盖按钮。

其他标签页自动保存视图也会改变整体 revision。冲突提示中的「重新读取」与左下角刷新使用同一草稿保护；没有草稿可直接同步，有草稿会先提示处理。不会自动采用旧 revision 或悄悄重试。建议同一工作区主要使用一个编辑页面。

新建分析图通过完整文件发布直接进入发现集合，不再另写清单。已有同名文件绝不覆盖；请求结果不明时应重新读取，不能自动重试。创建失败可能留下已经创建的空父目录；替换提交后确认失败或连接中断提示结果待确认。

只支持本地磁盘的单服务工作方式，不承诺外部编辑器并发写入的原子 CAS、掉电恢复、多文件事务、网络共享盘或多人协作。页面打开期间没有文件监听；需要读取外部最新修改时点击重新读取或刷新。保存期间不要让其他程序改写同一工作区。
