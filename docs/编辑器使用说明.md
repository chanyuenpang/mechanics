# 网页节点编辑器

本地服务从启动时固定的工作区根读写 JSON，显式参数优先，否则向上定位。根路径显示在侧栏；不连接游戏运行时，不使用浏览器缓存代替保存。界面为浅色极简样式：左侧文件目录，其余区域为画布或节点名词表；属性在需要时浮出，侧栏可以收起。

## 文件与图层

- `统一节点定义`：创建和修改概念名称、含义、增加方向、默认位置。稳定 ID 不随名称变化。
- 根内任意普通目录的 `*.analysis.json` 是一个 Layer，`analyses/` 是默认落点。点名称指定编辑层，勾选控制是否叠加显示。选为编辑层时会显示该层；隐藏编辑层会切换到另一个可见层，或回到节点定义。
- 实线节点和较深关系属于当前层；浅色虚线节点、浅色关系是其他层的参考内容。共享节点按 ID 接合，只显示一个节点。
- 修改关系只写当前层文件。其他层的边不可直接修改，属性面板提供跳转来源层的按钮。
- 拖动当前层引用的节点只修改当前层的局部位置；定义图拖动修改默认位置。当前层局部位置优先，其次组合位置，再次共享默认位置。切换编辑层时可能呈现该层自身布局。
- 文件树按服务从磁盘发现的真实路径生成，包括空目录；显示名用于辨识，悬停可查看完整相对路径。外部新增/移动后重新读取，无需手工登记。

## 节点名词表

点击「统一节点定义」默认进入名词表，可随时切到「节点图」。表格参考 SJE Array 的紧凑表头、弱分隔线、行内输入和内部滚动样式，但工具不依赖 SJE 或宿主代码。

直接点击名称、概念含义、增加方向编辑；点击「新增概念」或表尾「新增一行」创建草稿行并聚焦名称。稳定 ID 自动生成且只读，改名不改引用。三项定义必填，未完整填写无法保存，草稿会保留。顶部搜索按名称、ID、定义或方向筛选，不修改文件。行内箭头切到画布查看；删除仍检查所有图层引用，已引用概念不可直接删除。

表格与画布使用同一份定义草稿、撤销历史和保存队列。切换两种视图不要求保存，也不会复制数据；离开定义文件仍走保存/放弃/取消保护。名称变化会在节点图呈现；保存后重新读取保留修改。按 Ctrl+S 或顶部保存按钮落盘。

## 建图

1. 点击「统一节点定义」，在表格直接新增概念并填写含义与增加方向，或切到节点图用底部「＋节点」，然后保存。
2. 点击侧栏文件区的「＋」创建分析图层，填写名称、文件 ID、分析范围和相对目录。支持中文嵌套目录；填 `.` 表示根目录。此操作创建实际 JSON 文件，不写额外登记清单。
3. 在分析图层点击「＋节点」，搜索并勾选需要引用的共享概念。
4. 点击「＋→」或「−→」，依次点击源节点和目标节点。两端必须已被当前层引用。符号表示促进或抑制，不是对玩家的好坏。
5. 选中节点或边，在浮动属性面板修改说明、符号或移除引用。再次点击当前图层名称可编辑名称与范围。
6. 点击「保存」或按 Ctrl+S。画布上的修改立即成为草稿，只有保存成功才会显示「已保存到项目」。

新概念必须先在统一定义中保存，再到分析层引用；不把两份文件的修改假称为一次原子事务。被任一图层引用的共享定义禁止删除。移出当前层会同时移除该层连接此节点的边，不修改其他层或全局定义。

## 叠加与视图记忆

显示开关、当前编辑层、折叠和展开操作自动保存到 `workspace.json.lastView`。重新打开网页或服务后恢复选择，并重新读取各图层文件，不保存合并图副本。没有该字段的 v2 工作区首次打开显示所有分析图并开始记忆；v1 须先显式迁移。表格/节点图切换和搜索是临时 UI 状态。

侧栏「叠加组合」旁的「＋」可另存命名组合。点组合名称恢复选图、折叠和组合位置；点 `workspace.json` 可查看和移除命名组合，不删除源图。命名组合与最近视图都保存引用，不冻结规则内容。

折叠只在文件已保存、节点单入单出且不在有向环中时开放。摘要保留原始关系与来源，不能直接编辑；「展开节点」恢复源图。修改拓扑前展开摘要。外部修改导致已保存折叠不再成立时明确报错，用户可主动展开，不静默修复模型。

规则文件不会自动保存。切换编辑文件时，如有草稿，会询问保存、放弃或取消。关闭或刷新有草稿、未完成写入或视图保存失败的页面时，浏览器会提示。视图写入失败不会显示为保存成功。

## 画布操作

| 操作 | 效果 |
| --- | --- |
| 拖拽节点 | 修改当前文件的布局 |
| 空白处拖拽、空格拖拽或中键拖拽 | 平移画布 |
| 鼠标滚轮、右下角加减 | 缩放 |
| F 或右下角适应按钮 | 将节点适应当前画布 |
| V / Esc | 返回选择工具 / 取消选择 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做当前文件操作，最多 80 步 |
| Delete | 删除当前层的关系或请求移除节点 |
| 结构提示 | 查看当前可见图层中的设计疑点 |
| 节点属性中的路径解释 | 追踪有限简单路径与来源，不推断胜率或净收益 |

撤销记录只属于当前页面中的当前文件，不跨文件或刷新恢复。保存不清除撤销历史；保存后撤销会形成新的未保存草稿。画布相机位置和缩放比例是临时交互状态，不属于最近视图的持久化内容。

## 文件安全与失败

同一工作区只允许一个服务持有 `.rule-analyzer.lock`，浏览器多标签可连接同一服务。正常 Ctrl+C 关闭会释放锁。异常退出留下锁时，应确认无服务仍在使用该目录后手动清理；服务不凭 PID 自动抢锁。

每次保存校验整体 revision 和全工作区引用，然后使用同目录临时文件、flush、close、rename、回读确认。过期版本返回冲突，保留草稿；可先「导出 JSON」，再重新读取磁盘并手动合并。不提供强制覆盖按钮。

其他标签页自动保存视图也会改变整体 revision。冲突提示中的「重新读取」与左下角刷新使用同一草稿保护；没有草稿可直接同步，有草稿会先提示处理。不会自动采用旧 revision 或悄悄重试。建议同一工作区主要使用一个编辑页面。

新建分析图通过完整文件发布直接进入发现集合，不再另写清单。已有同名文件绝不覆盖；请求结果不明时应重新读取，不能自动重试。创建失败可能留下已经创建的空父目录；替换提交后确认失败或连接中断提示结果待确认。

只支持本地磁盘的单服务工作方式，不承诺外部编辑器并发写入的原子 CAS、掉电恢复、多文件事务、网络共享盘或多人协作。页面打开期间没有文件监听；需要读取外部最新修改时点击重新读取或刷新。保存期间不要让其他程序改写同一工作区。
