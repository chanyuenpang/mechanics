# 开发路线与验收边界

## 已完成：文件协议与可视化编辑

- 独立仓库、JSON Schema、统一定义图、分析图与组合，宿主通过子模块接入。
- 显式工作区、全量引用校验、版本戳、受限读写、工作区锁与串行写入。
- 左侧真实文件目录、全屏节点画布、Layer 显示与编辑归属分离。
- 新建分析图、共享概念维护、引用节点、正负连线、文字说明、拖拽位置、缩放平移、撤销重做和保存。
- 叠加、路径解释、来源检查、可逆折叠和限定范围的结构疑点。
- 最近视图自动保存，恢复可见层与编辑层，重开使用源文件最新内容；历史命名组合保留，界面不再提供单独分类。
- 可安装 CLI、稳定工作区根与递归目录发现；v1 显式迁移预检、文件集合保护和原配置备份。
- 顶部全局概念表/分析图，侧栏只列分析文件；新增概念、引用概念与新建分析图分别拥有明确入口，切换前保护当前文件草稿。

自动验证通过 `npm run check` 的 25 项行为测试；`npm run check:package` 验证实际安装包、命令 shim、仓库外启动及静态资源。浏览器在隔离工作区验证名词表、全局切换和草稿取消、定义保存不改分析文件、图层/折叠保留、引用定位、空工作区首张图、中文嵌套目录及刷新恢复。测试不写真实设计文件，不调用宿主游戏运行时。

保存限制、错误处理和具体操作见[编辑器使用说明](编辑器使用说明.md)。单文件替换不等于多文件事务；未做掉电或真实磁盘故障注入验证，不承诺网络共享盘及多人协作。

## 后续可独立评估

- 自动布局与更大图的导航、搜索、多选操作。
- 明确引用影响后的图层删除、节点合并、跨文件重构。
- 外部文件变化提示与草稿差异合并；不引入自动覆盖。
- 导出图像与更完整的可访问性、触屏交互。
- agent 可调用的结构查询与证据输出。

当前没有规则内容自动保存、跨文件撤销、相机持久化、实时文件监听或云发布。

## agent 优化试验

面向抽象规则设计，先以相同规则事实和固定问题对比纯文本与文本＋图：机制协同/反制检索、覆盖缺口、代价路径、结构相似、证据完整度、耗时和 token 成本。只要敌人产出近战，抑制近战的规则即可被识别为反制路径，不需要先核对具体战局条件。实时战斗策略、可执行条件、实例绑定与规划搜索不属于这一试验目标。

拟议优化见[模型对 agent 的价值与优化讨论](模型对agent的价值与优化讨论.md)，它们不在当前协议中隐式生效。
