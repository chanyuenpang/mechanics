# 开发路线与验收边界

## 已完成：文件协议与可视化编辑

- 独立仓库、JSON Schema、统一定义图、分析图与组合，宿主通过子模块接入。
- 显式工作区、全量引用校验、版本戳、受限读写、工作区锁与串行写入。
- 左侧真实文件目录、全屏节点画布、Layer 显示与编辑归属分离。
- 新建分析图、共享概念维护、引用节点、正负连线、文字说明、拖拽位置、缩放平移、撤销重做和保存。
- 叠加、路径解释、来源检查、可逆折叠和限定范围的结构疑点。
- 研究点击独立编辑；只有 `.view.json` 显示勾选并自动写回成员、位置和折叠，源规则只读。编辑源研究后一键返回，恢复组合布局与本页相机。旧内联叠加只读保留，明确保存或放弃；旧视图首次展示编辑才接管位置。
- 可安装 CLI、稳定工作区根与递归目录发现；v1/v2 显式升级 v3，预检、文件集合保护和按原版本备份。
- 顶部全局概念表/分析图，侧栏混排分析与视图文件；新增概念、引用概念、新建分析图与保存为视图分别拥有明确入口。

0.5.0 自动验证通过 `npm run check` 的 53 项测试，新增包含继承/反证、版本升级、成环拒绝、右键框选与整组移动。`npm run check:package` 通过 Windows 隔离安装、命令 shim、仓库外启动及静态资源验收。浏览器验证黄色关系、路径证据、升级撤销保存、Shift 多选后的整组拖动、研究/视图保存归属与冲突暂停；右键框选使用 canvas 手势自动化用例验证。保留 0.4.0 单图/视图导航、旧记录和折叠修复覆盖。测试不写真实设计文件，不调用宿主游戏运行时。

保存限制、错误处理和具体操作见[编辑器使用说明](编辑器使用说明.md)。单文件替换不等于多文件事务；未做掉电或真实磁盘故障注入验证，不承诺网络共享盘及多人协作。

## 后续可独立评估

- 自动布局与更大图的导航、搜索、多选操作。
- 明确引用影响后的图层删除、节点合并、跨文件重构。
- 外部文件变化提示与草稿差异合并；不引入自动覆盖。
- 导出图像与更完整的可访问性、触屏交互。
- agent 可调用的结构查询与证据输出。

当前没有规则内容自动保存、跨文件撤销、相机持久化、实时文件监听或云发布。

## agent 优化试验

面向抽象规则设计，先以相同规则事实和固定问题对比纯文本与文本＋图：机制协同/反制检索、覆盖缺口、代价路径、结构相似、证据完整度、耗时和 token 成本。只要敌人产出近战，抑制近战的规则即可被识别为反制路径，不需要先核对具体战局条件。实时战斗策略、可执行条件、实例绑定与规划搜索不属于这一试验目标。

拟议优化见[模型对 agent 的价值与优化讨论](模型对agent的价值与优化讨论.md)，它们不在当前协议中隐式生效。
