## 当前行为

- 顶部只有「概念表｜分析图」两种工作视图。0.5.1 侧栏改为上方视图、下方研究，替代历史混排；实际文件路径不变，不在每个视图下复制研究树。两区加号新建对应类型；从研究存为视图/视图另存为移至画布上方。workspace.json、统一定义文件和旧命名组合不作为导航项。磁盘研究后缀仍为 `.analysis.json`，视图行不可勾选。
- 研究区及真实目录可折叠，按名称、ID 或相对路径筛选；只呈现有匹配文件的目录，不显示空目录占位。搜索临时展开目录，清除恢复原折叠。sidebarState 属于 app 页面会话，不改变画布、视图成员、撤销或文件，不复用节点折叠。已选数统计当前视图全部成员，包含隐藏结果。
- 新研究成功创建并独立打开后清除筛选、展开所在目录，不自动加入原视图；创建成功但打开失败仍明确报告已创建路径。目录重组不改变保存队列、草稿保护或文件协议。
- 0.5.2 按用户要求改为左键空白框选、右键平移；替代 0.5.0 的右键框选。Shift 增选、左键节点拖动、空格与中键平移保留。普通左键空白轻点清除选择，Shift 轻点保留；右键仅改相机，在节点上或连线模式也可平移，不清除选择或写节点位置。
- 「新增概念」创建共享定义草稿行，「引用概念」将稳定 ID 加入当前图的 nodeIds，「新建分析图」创建独立 JSON 文件。空工作区可以先建概念，再建首张图并引用。
- 概念表借鉴 SJE Array 的紧凑表格样式，不依赖 SJE。名称、含义、增加方向可行内编辑，三项必填；稳定 ID 自动生成且只读。引用检查覆盖所有持久化图，被引用概念不能删除。
- 顶部工作视图与记住的分析层分别管理。概念表草稿归定义文件；分析图草稿归当前分析文件。不能根据保留的 activeId 推断定义保存目标。
- 进入概念表保留原分析层、可见层、折叠和布局；返回分析图继续原范围。纯切换和定义文案编辑不写 lastView、不清空折叠。行内「查看引用」跳到所属图并定位节点，必要时主动展开该节点。
- 点击研究只打开自身关系，规则和局部位置手动保存；研究模式没有勾选。只有打开视图才能勾选研究，视图只拥有成员、组合位置、折叠并自动保存，源规则只读。点击研究退出视图不改变原视图成员。
- 「编辑源研究」进入单图，随后「返回视图」读取最新来源并恢复视图位置和本页相机。研究拖动只改研究，视图拖动只改视图；新节点确定摆放，不抢占已有位置。勾选变化只清理失去引用的位置与失效折叠，整步可撤销。
- 页面只有一份当前规则草稿。跨文件/工作视图切换前提供保存、放弃、取消；规则撤销形成手动草稿，视图撤销再次自动保存，不跨文件/刷新撤销。相机按文件在会话记忆，返回恢复但不落盘；普通点选不强制 fit。
- 0.2.1 只移除历史组合的界面入口，保留 compositions 协议、原记录和校验，不迁移或删除用户数据。
- 0.3.0 新增真实 `.view.json`；0.4.0 分离研究/视图模式，替代原同屏编辑层交互。命名 lastView 只存 `{viewId}`，研究保存单成员内联最近记录，不保存临时折叠和相机。新视图从空集合开始，也可从研究创建。创建与最近记录两次提交；后一步失败须报告已创建路径，不重建或自动删除。
- 旧多图或带展示状态的内联记录启动只读保留，须明确保存为视图或放弃；无记录只打开第一张研究。旧命名视图按非空 activeLayerId 物化原坐标，打开不写文件，首次展示编辑保存位置并将该字段置空。沿用工作区 v3、文档 v1，无额外迁移。
- 外部规则使保存的折叠失效，须明确确认展开修复才写视图；坏文件或断引用仍整体拒绝。研究删除可能破坏视图位置/折叠引用时先列出受影响文件，不自动联动清理。
- 打开视图始终重新读取完整源文件，验证候选投影和折叠后才替换当前 UI。选择放弃草稿后若目标打开失败，原草稿仍保留。写入串行捕获目标与快照，自动保存失败暂停后续自动写入，规则和视图状态分别显示；视图与规则草稿分别导出，显式重读后恢复。
