# 抽象游戏规则模型

## 当前行为

- 工具分析抽象规则，不模拟实时战局。敌人促进近战、后撤步抑制近战，即可通过共享概念识别机制反制；不以前置实例绑定、某局体力或行动可用性判断作为查询条件。
- 一个工作区只有一份概念定义图，拥有稳定 ID、名称、含义、增加方向及默认位置。各分析图只引用概念并拥有自己的关系与局部布局。同名不同 ID 不合并，改名不改引用。
- `sign: 1` 表示促进，`sign: -1` 表示抑制；正负不表示对玩家有利与否。消耗是行动对资源的负向作用，资源支持行动是另一条关系。
- `src/domain/graph.mjs` 拥有纯图函数。组合保留来源、同向并行边和异向边，没有覆盖优先级，不把正负作用直接抵消。当前可见分析图集合限定查询范围，不等于当前回合激活集合。
- 有限简单路径保留方向、符号、机制说明与来源，并报告截断。符号相乘仅解释单路径促进/抑制，不推断影响强度、净收益、胜率或动态闭环结果。
- 单入单出且不在有向环中的节点可以折叠；摘要保留全部原始路径，展开可恢复。折叠只改视图，不删除概念或原边，不把摘要当作可编辑事实。
- 孤立、只有输入、相似结构都是设计疑点，不自动判坏、合并或删除；终点、消耗出口、未覆盖范围可能合理。未被选图引用的全局定义不属于当前图的孤立节点。
- Schema 的唯一来源是 `schemas/protocol.schema.json`；跨文件校验归 `src/domain/validate.mjs`。未知版本、无效引用或条件缺失不以默认值修复。

## 验证边界

2026-08-31 的 `npm run check` 通过 25 项行为测试，其中图测试覆盖稳定身份、来源、异号关系保留、折叠展开、循环限制、路径截断、疑点边界与非卡牌游戏工作区。未实现实时条件求值、AND/阈值/概率求解、自动规则提取或 agent 专用查询接口。

详细合同见 `docs/文件协议.md`、`docs/架构设计.md` 与 `docs/模型对agent的价值与优化讨论.md`。讨论中的优化不是已实现能力。
