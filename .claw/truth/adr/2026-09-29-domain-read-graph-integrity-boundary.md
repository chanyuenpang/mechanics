# ADR：领域拥有读取图完整性，布局只复核

## 背景

端点限定替代基础节点、分类隐藏和机制合成会生成不同阶段的读取图。若保留边的端点不在当前节点集中，布局的连通分量或模块体积计算可能在几何访问中产生难定位的错误；局部兜底又可能遮蔽投影缺陷。

## 决策

- 领域层负责读取图的不变量：节点 ID 唯一且有效，每条保留边的两端都在同一图中；合成和投影阶段显式检查输入或输出。布局与 Worker 在计算入口复核同一断言，而不另行定义宽松语义。
- 不通过补造默认节点、静默丢边或布局局部兜底修复坏图；错误标明阶段及受影响端点。该约束只针对读取投影，不改变 canonical 文件协议及已有文件引用校验。
- 自动布局以成功提交几何为安排自动保存的条件；失败不得提交部分几何或因该次布局触发保存。

## 取舍

- 只在布局中处理 `undefined.volume`：拒绝。它无法说明坏图产生于合成、限定还是显示投影。
- 生成缺失节点或过滤悬空边：拒绝。它让错误的读取语义看似成功，且可能改变焦点与正常 is-a 隐藏行为。
- 在每一层重写独立校验：拒绝。共用领域断言使诊断及不变量保持一致，布局只做边界复核。

## 影响

- 当前事实与代码锚点由[读取图端点完整性](../features/read-graph-integrity.md)维护；限定节点的隐藏条件仍由[端点限定词投影](../features/endpoint-qualifier-projection.md)维护。
- 已完成的回归覆盖缺端点、无效/重复节点、混用限定、正常隐藏和失败布局事务；发布并安装后的目标游戏图真实打开验收仍待执行，不以单测代替。
