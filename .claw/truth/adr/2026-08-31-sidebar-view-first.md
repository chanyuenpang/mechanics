# 侧栏视图优先，机制筛选只改变导航投影

日期：2026-08-31
状态：accepted

## 背景

真实目录混排让视图排在机制后面，大按钮和常驻路径占用空间。用户要求视图置顶，并给机制增加折叠、筛选和明确的新建入口；也提出可在视图下嵌套机制作为备选。

## 决策

采用上方视图、下方单一机制目录。视图引用稳定机制 ID，机制不属于某个视图，因此不为每个视图复制目录树。两区加号分别创建空白视图或独立机制；新机制不自动加入原视图。从机制存为视图、另存为及旧叠加保存保留在画布上方。

机制名称、ID、相对路径筛选及目录折叠只属于页面会话，不存入视图或 workspace.json，不改变成员、画布或撤销。搜索时临时展开匹配目录，清除恢复折叠；已选数始终取视图完整成员。服务继续发现完整目录，侧栏不展示空目录占位，文件真实位置与协议不变。

## 验证与边界

隔离浏览器验证两个视图切换、勾选归属、机制独立打开、新建不自动加入、概念表往返、焦点与键盘折叠。纯导航筛选/折叠期间八份 JSON 及画布 DOM 不变，视图编辑阶段原四份机制哈希不变。筛选和目录折叠不跨刷新恢复；不新增视图套视图、文件移动或删除能力。
